# Changelog

Release notes for every version are published on the [GitHub releases page](https://github.com/pedrosodre/nestjs-config-extended/releases).

They are generated automatically by [semantic-release](https://semantic-release.gitbook.io) from the [Conventional Commits](https://www.conventionalcommits.org) merged since the previous release, grouped into features, bug fixes and breaking changes. Prereleases from the `next` branch are marked as pre-releases.

Upgrading from 1.x? See the [migration guide](MIGRATION.md).
